# Реализация шума в режиме обучения

## Обзор изменений

В код MCTSAgent добавлена логика применения Dirichlet шума к политике нейросети в режиме обучения. Это помогает агенту исследовать различные варианты ходов и избегать преждевременной сходимости к локальным оптимумам.

## Внесенные изменения

### 1. Модификация метода `get_move` в `RL_agent.py`

- **Добавлен параметр** `is_training=False` в сигнатуру метода
- **Добавлена логика шума** между `batch_predict` и `root.expand`
- **Добавлено логирование** для отладки и сравнения политик

### 2. Обновление вызова в `RL_train.py`

- **Изменен вызов** с `agent.get_move(board)` на `agent.get_move(board, is_training=True)`
- **Добавлен комментарий** о режиме обучения

### 3. Режимы работы

- **Режим игры** (`is_training=False`): Используется "чистая" политика от нейросети
- **Режим обучения** (`is_training=True`): Применяется Dirichlet шум к политике

## Детали реализации

### Параметры шума

```python
# Параметр alpha для Dirichlet шума (стандартное значение для шахмат)
alpha = 0.3

# Пропорция смешивания: 85% оригинальная политика + 15% шум
mix_ratio = 0.85  # оригинал
noise_ratio = 0.15  # шум
```

### Алгоритм применения шума

1. **Получение чистой политики**: `init_policy = policies[0]`
2. **Генерация шума**: `noise = np.random.dirichlet([0.3] * len(legal_moves))`
3. **Смешивание**: `noisy_policy[move] = 0.85 * init_policy[move] + 0.15 * noise[i]`
4. **Нормализация**: Обеспечение суммы вероятностей = 1.0
5. **Применение**: `root.expand(noisy_policy)`

### Логирование

Система логирования записывает в файл `thinking_log.txt`:
- Чистую политику (топ-5 ходов)
- Зашумленную политику (топ-5 ходов)
- Сравнение изменений в рейтинге ходов

## Как проверить работу


### 2. Проверка логов

### 3. Признаки работы шума

- **Изменение порядка ходов**: Топ-5 ходов в зашумленной политике должны отличаться от чистой
- **Изменение вероятностей**: Все вероятности должны быть слегка изменены
- **Исследование**: Иногда ходы с низкой вероятностью должны "выстреливать" в топ

## Технические детали

### Безопасность и стабильность

- **Проверка на пустые ходы**: `if len(legal_moves) > 0:`
- **Нормализация**: Гарантирует сумму вероятностей = 1.0
- **Обратная совместимость**: Параметр `is_training` имеет значение по умолчанию `False`

### Производительность

- **Минимальные накладные расходы**: Шум применяется только к корневому узлу
- **Однократное применение**: Шум не влияет на дальнейшие симуляции MCTS
- **Эффективная генерация**: Использует оптимизированную функцию `np.random.dirichlet`
